Создание этого проекта было для меня сложной задачей - создать игру на новом языке.
Целью этого проекта было написать простую логическую игру без рекламы,
ориентированную на среднестатистического игрока.
Главное меню игры.

Это первый экран приложения, который появляется после запуска.
Он сосотоит из блока навигационных кнопок, логотипа игры, главных кнопок и версии приложения
Для навигации использую navigation compose.
В игре есть 2 режима игры.
Приключения - режим где необходимо поткрыть 200 свиткоы, каждый свиток это отдельный уровень.
Выживание - режим бесконечной игры с постепеным усложнением логики.
В игре можно создавать игроков есть таблица рекордов
Ui написан на фреймворке Compose.
Игра поддерживает поворот экрана.

Кнопки звук и смены языка игры сделаны компонентом IconToggleButton
Основной блок кнопок сделан компонентами IconButton
