Приключения - вам нужно открыть 200 свитков,
каждый из которых представляет собой уровень, на котором нужно выполнить задания.
Собирая комбинации из цветных кристаллов, вы набираете очки.
При наборе необходимого количества очков уровень считается успешно пройденным.
Для этого у вас есть ограниченное количество ходов,
а на игровых площадках есть препятствия, которые необходимо преодолеть
Приключения.

Карта состоит из 200 свитков-уровней, реализована компонентом LazyVerticalGrid.
Нажимая на свиток запускается основное поле игры.
Поле игры.


Размер игрового поля меняется от сложности уровня.
Слева вверху находится блок с информацией об игроке,
каждый игрок имеет свой уникальный прогресс.
На поле расставлены препятствия в виде камней и травы,
сбрасывая линии выигрыша, вы повреждаете препятствия.
Камень уничтожается за два раза, трава при первом сбросе.
Анимция повреждения и уничтожения сделана спрайтами - sprite.
Появление кристаллов реализовано Compose animation.
Так же предусмотрены бонусы для помощи в игре,
они открываются по мере набора очков.
Перемещение сделано встороенным функционалом pointerInput
Для взаимодействия объектов написана своя логика колизий.
Она следит за столкновением объектов, вычисляет доступные ячейки для кристаллов и бонусов.
Для оптимизации использую Kotlin Coroutine и просчитываю координаты только в момент движения.
Обновление Ui с помощью compose state.
Настройка уровней происходит файлом конфигурации доступным для гейм дизайнера.
Однако написан свой генератор уровней.
Введя желаемое количество уровней, логика сконфигурирует постепенное усложнение.
Гейм дизайнер может настроить как отдельные так и все уровни.

Пример книжного режима экрана.
Для этого использую отдельную верстку расположения компонентов.
